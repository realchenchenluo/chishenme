# 校园菜单包

这里的每个文件是一所学校（或一个食堂、一片大学城）的菜单数据，导入「今天吃什么」之后，抽签用的就是你身边真实的价格和菜名。

## 文件格式

```json
{
  "id": "suibian-daxue-yitang",
  "name": "随便大学 · 一食堂",
  "school": "随便大学",
  "city": "武汉",
  "place": "canteen",
  "count": 2,
  "note": "标签是我自己标的，可能不准",
  "dishes": [
    {
      "n": "三楼红烧肉",
      "p": "canteen",
      "price": [15, 15],
      "wait": [8, 15],
      "r": 4.6,
      "t": ["米饭", "猪肉", "重口"],
      "d": "三楼窗口，肥而不腻，阿姨给的肉块比别家多"
    }
  ]
}
```

每条菜品的字段（除了 `n` 都建议填）：

| 字段 | 说明 |
| --- | --- |
| `n` | 菜名（必填） |
| `k` | 包内稳定编号（可选）。同一道菜在不同窗口各有一份时，用它区分，不要用菜名 |
| `p` | `canteen` 食堂 / `takeout` 外卖 / `both` 两边都有 |
| `price` | 价格区间 `[最低, 最高]`，单位元。价格固定就写两个一样的数 |
| `wait` | 等待分钟区间 `[最短, 最长]`，含排队和出餐 |
| `r` | 好吃度 3.0–5.0，参与抽签权重。**没把握就填 4.0** |
| `t` | 标签数组，见下 |
| `d` | 一句话点评（会给别人看，写点有用的） |

标签用这几套词，其他词筛不到：

- 类型：`米饭` `面食` `粉汤` `小吃` `轻食` `烧烤` `油炸` `甜品` `饮品` `套餐`
- 口味：`辣` `微辣` `重口` `清淡` `甜`
- 食材（**忌口筛选靠它，请尽量不要漏**，尤其是猪肉）：`牛肉` `羊肉` `猪肉` `鸡肉` `鸭肉` `海鲜` `内脏` `蛋` `素食可选` `香菜`

## 怎么提交

1. Fork 这个仓库
2. 把你的菜单存成 `packs/<学校拼音>-<食堂>.json`（照上面的格式，`id` 和文件名保持一致）
3. 在 `packs/index.json` 的 `packs` 数组里加一条，把 `count`、`source`、`license`、`attribution` 填清楚
4. 提 PR

不想折腾 Git 的话：在应用里「我的 → 我的菜单 → 导出备份」拿到 JSON，开个 [issue](https://github.com/realchenchenluo/chishenme/issues) 贴上来，或者发给项目的维护者，我们帮你转成包。

## 三条硬规矩

**0. 照片不要进仓库（隐私）。**
拍菜单照片整理数据时，**只提交提取出来的 JSON**，不要把照片本身放进仓库。手机照片默认带 **EXIF 定位信息**（拍摄地 GPS 坐标），一旦提交就永久留在公开的 git 历史里，删都删不干净。图片对使用者也没有价值——有菜名和价格就够了。

**1. 只提交你有权共享的数据。**
自己一道道敲的没问题；从别的仓库搬的，必须那个仓库**有明确许可**（CC BY、MIT 等），并在 `attribution` 里写清署名。**没有 License 就是默认保留全部权利，不要搬。** 目前已知清华、北师、对外经贸几个食堂数据仓库都没有 License，只能自己去联系作者要授权。

**2. 不要从美团、大众点评、小红书搬运评价原文。**
这些是第三方内容，且平台条款也禁止。菜名和价格是事实性信息，自己整理没有著作权问题；但**别人写的评价文字不要抄**——想写点评就自己写一句。

**3. 说清楚哪些是推断的。**
标签、等待时间、评分如果你不是实测的，就在 `note` 里写明「标签是推断的」「等待时间是估的」。宁可不填，也别让人以为那是精确数据。

## 做了什么转换（现有包的说明）

`szu-nanqu-2f.json` 来自 CC BY 4.0 的数据集，转换脚本是 [`tools/make-pack-szu.mjs`](../tools/make-pack-szu.mjs)，可以自己跑一遍复核：

1. 字段改名对齐本站格式
2. **菜名和价格原样保留**，一个数都没改
3. 按菜名和原数据的 `remark` 备注推断口味与食材标签
4. 按窗口类型补充等待时间估算（**源数据没有这个字段**）
5. 好吃度源数据没有，统一填 4.2（**不是真实评分**）

想自己复现：把源仓库的 `data/2026-szu-south-canteen-2f/menu.json` 下载下来，然后

```bash
node tools/make-pack-szu.mjs /path/to/menu.json
```
